# Megaline-Plan-Revenue-Analysis

Project Description
This project analyzes customer behavior for a telecom company (Megaline) offering two prepaid plans: Surf and Ultimate.
The objective is to determine which plan generates higher average revenue and provide insights to support marketing budget decisions.

Dataset
The analysis is based on data from 500 customers, including:

Customer demographics

Plan type

Call duration

SMS usage

Internet usage

Monthly revenue (2018)

Key Tasks

Data loading and initial exploration

Data cleaning and preprocessing

Feature engineering

Exploratory Data Analysis (EDA)

Statistical hypothesis testing

Business-oriented conclusions

Analysis Highlights

Compared average revenue per plan

Analyzed usage patterns (calls, messages, data)

Applied statistical tests to validate revenue differences

Identified which plan generates higher profitability

Tools & Technologies

Python

Pandas

NumPy

Matplotlib

SciPy

Jupyter Notebook

Key Conclusion
The analysis identified the plan that generates higher average revenue, providing actionable insights for marketing and pricing strategy optimization.
